# 🚀 Cloud Cost Governance System

An intelligent cloud cost optimization system that analyzes AWS resource usage and provides actionable recommendations to reduce cloud spending.

---

## 📌 Features

- ✅ Real-time AWS cost analysis using Cost Explorer
- ✅ EC2 resource monitoring
- ✅ Rule-based optimization (Stop / Resize / Keep)
- ✅ Cost-saving recommendations with estimated savings
- ✅ Interactive dashboard (Flask-based)
- ✅ Clean modular pipeline architecture

## 📊 Dashboard Capabilities

- Total cost analysis
- Running EC2 instances tracking
- Resource-level optimization insights
- Priority-based recommendations:
  - 🔴 HIGH → Stop / Terminate
  - 🟡 MEDIUM → Resize
  - 🟢 LOW → Keep running
